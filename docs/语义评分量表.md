# 语义特征评分量表（Rubric v2.0）

> 用途：① 队员人工评分的统一标准；② LLM prompt 的核心组成部分（量表原文嵌入 prompt）；③ 论文中回答"AI 打分凭什么可信"的凭据。三个维度均为 0–10 分，五档锚定。**硬规则：评分 ≥5 分必须附原文证据；找不到证据支撑的高分一律作废。**
> v2.0 变更（2026-11-18）：维度一由"业绩夸张度"改为"资金与债务异常信号"——16 篇测试显示"业绩夸张度"无法区分舞弊与对照（AUC≈0.5），而资金/债务异常是舞弊红旗（存贷双高、资金占用）；聚合改用"均值+峰值"（峰值区分度显著更强）。

## 维度一：资金与债务异常信号（financial_anomaly）

测量"文字是否透露资金链紧张、资金被占用、存贷双高、利润无现金支撑等舞弊高危迹象"。对应舞弊三角之**压力/动机**（资金压力）。

| 分数档 | 锚定定义（可观察的文本行为） |
|---|---|
| 0–2 无异常 | 资金、债务、现金流描述与经营情况匹配，披露清晰 |
| 3–4 常规 | 无明显资金异常信号 |
| 5–6 有迹象 | 出现"高存款与高借款并存""资金被关联方占用""应收账款回款周期异常拉长"等迹象但未给出解释 |
| 7–8 明显异常 | 文字暗示资金链紧张、债务逾期风险、利润与经营现金流明显背离、大额其他应收款缺乏合理解释 |
| 9–10 高度吻合 | 文字与"存贷双高、资金占用、利润无现金支撑"等舞弊标志直接吻合，或对此给出牵强、自相矛盾的解释 |

## 维度二：风险掩饰度（risk_concealment）

测量"风险披露章节对真实风险的覆盖程度"。对应舞弊三角之**态度/合理化**。

| 分数档 | 锚定定义 |
|---|---|
| 0–2 充分披露 | 风险因素具体、有量化、与公司实际紧密相关（如明确指出补贴退坡对收入的具体影响幅度），并有可核查的应对措施 |
| 3–4 模板化 | 风险披露为行业通用模板（"市场竞争风险""政策风险"），缺乏公司特异性，但未回避已知重大风险 |
| 5–6 避重就轻 | 重大风险仅以一句话带过、无量化（如对占收入三成的补贴仅称"可能存在政策变动风险"） |
| 7–8 明显回避 | 已发生的负面事件（诉讼、监管问询、大客户流失、债务逾期）在风险章节只字未提 |
| 9–10 粉饰太平 | 明确否认客观存在的风险，或将重大不利变化描述为"无重大影响""不会对公司造成不利后果" |

## 维度三：未来画饼度（future_promises）

测量"未来规划与资源约束之间的脱节程度"。对应舞弊三角之**机会**（以叙事吸引资金、维持股价的空间）。

| 分数档 | 锚定定义 |
|---|---|
| 0–2 务实 | 未来计划含具体产能、时间表、资金来源（如"拟以定向增发募资 X 亿元建设 Y 项目"） |
| 3–4 常规展望 | 方向性描述为主，含少量可核查目标 |
| 5–6 宏大叙事 | 大规模扩产/转型计划，但缺乏资金安排、技术来源、可行性论证等细节 |
| 7–8 脱离约束 | 规划规模明显超出经营现金流与融资能力，或与行业产能过剩现状明显脱节 |
| 9–10 空想承诺 | 历史上同类承诺未兑现，本期提出更宏大的新承诺；或以未来叙事直接回应当期亏损质疑 |

## 使用规程

1. **打分粒度**：0–10，允许 0.5 步进；评分 <5 分可不附证据，≥5 分必须附原文 quote。
2. **聚合规则**：MD&A 分块评分后，同时记录各块**均值**与**峰值**；v2.0 起**峰值与均值并列为特征**（16 篇测试显示峰值 AUC 显著高于均值：future_promises_max 0.79 vs mean 0.68）。5 次重复（降级预案 2 次）取均值并报告标准差，标准差 >1.5 的样本标记为"模型不确定"，误差分析中单独讨论。
3. **人工一致性检验**：抽样 15–20 例，**两名队员独立盲评**（互不知晓对方与 LLM 的分数），与 LLM 分计算 Spearman 相关，并报告 **ICC 或 Krippendorff α**；人工评分前**先培训**：全体评同一篇样例、逐条对答案、统一分歧后再独立评分。
4. **迭代纪律**：量表与 few-shot 样例的修改只允许基于开发集，测试折数据不得用于调整本量表。
5. **版本固定**：固定模型版本、prompt 文本（记录 hash）、temperature、重复次数；任何一处变更须重跑全部样本并记录于实验日志。
6. **失败率报告**：逐例记录"引用子串校验失败率"（quote 不是 MD&A 原文子串的比例），作为评分可靠性的伴生指标纳入结果报告。
7. **脱敏强化**：除公司全称外，同时替换股票代码、子公司/项目独特名称等可识别实体；正文引用证据不受影响。报告**脱敏前后评分敏感性**（评分分布差异），排除模型凭训练记忆"认出"处罚公司的污染。
