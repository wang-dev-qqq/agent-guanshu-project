## 二、衍生特征血缘

`数据表_全部.csv`（原始 27 列，138 公司年）→ S2 按 Beneish 公式集计算 12 维财务特征（`财务特征12.csv`）→ 与 S4 语义三维、核验二维及外部二信号合并为 `特征表.csv`（96 个建模样本 × 19 维）→ S5 进行五组消融建模。

## 三、许可与合规说明

1. **公开披露信息**：本项目使用的年度报告、问询函件、行政处罚文书均为上市公司依法公开披露的信息，通过巨潮资讯网、沪深交易所官网、新浪财经等公开渠道获取，仅用于学术研究目的，不涉及任何非公开信息或内幕信息。
2. **官方统计数据**：行业增速来源于国家部委及行业协会公开发布的统计资料，属公共领域信息。
3. **LLM 服务**：语义评分与核验裁定通过 DeepSeek 官方 API 付费调用完成，遵守其服务条款；调用内容为公司公开披露文本，不含个人信息；模型版本（deepseek-flash、deepseek-v4-pro）与调用量在 Agent 使用日志中如实记录；截至 2026-11-21，项目期间累计消费 ¥32.00（deepseek-flash，2,145 次请求，12,115,517 tokens），账户余额 ¥40.54。
4. **个人信息**：本项目数据不涉及个人信息，无需进行个人信息保护合规审查。
5. **数据分发**：随研究包提交的数据文件为加工后的结构化数据（特征表、评分表、裁定表等）；原始年报 PDF 的版权归上市公司及披露平台所有，不随包分发，获取渠道已在上表注明。
