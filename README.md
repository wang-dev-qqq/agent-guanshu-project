山东财经大学智能体科研创新挑战赛（赛道四）提交代码仓库。本仓库包含从特征工程到模型评估的完整可复现流程，对应论文《基于多智能体审计交叉核验的新能源企业财务舞弊预警研究》。

## 三、运行方法

依赖：Python 3.10+，`pip install -r requirements.txt` 一次装齐。

**无 API key 也能复现的部分**（推荐评审走这条）：S2 → S5 → S5_置换 → S6 全部离线可跑——LLM 的中间产物（语义评分、声明、核验汇总）已随 `data/` 提供。需 API key 的仅 S4 与核验 v2 两个打分脚本（重算 LLM 评分）。

**辅助工具说明**：`问询对照核查.py`、`问询重提取_校准.py` 需联网调用巨潮资讯接口，属数据核验期的分析工具，非复现主流程必需；`脱敏重打分.py` 的输入（16 篇脱敏文本与对应表）在研究包而非本仓库，用于盲评一致性分析。

在仓库根目录按以下顺序运行（脚本已规范为根目录相对路径：读 `data/`，写 `results/` 与 `figs/`）：

```bash
python code/S2特征工程.py          # data/数据表_全部.csv → data/特征表.csv、data/财务特征12.csv
python code/S3建模.py              # 探索性基线（逻辑回归/随机森林），控制台输出
export DEEPSEEK_API_KEY="你的key"
python code/S4语义打分.py          # data/MD_A_*.json → 语义三维评分（需 API key，断点续跑）
python code/核验_v2_全量.py        # 声明-事实四分类核验（需 API key，断点续跑）
python code/S5建模.py              # 五组消融主评估 → results/results_summary.csv
python code/S5_置换检验.py         # 五组 ×1000 次置换 → results/results_perm.csv（可断点续跑）
python code/S6_SHAP.py             # 全局/个体 SHAP → figs/
python code/分类器稳健性_学习曲线.py  # 4.4节分类器对照(LR 0.894)与学习曲线 → results/
```

**安全说明**：涉及 LLM 的脚本（S4、核验 v2、脱敏重打分）通过环境变量 `DEEPSEEK_API_KEY` 读取密钥，仓库内不含任何密钥明文。复现 S5/置换/S6 无需 API key。

## 四、模型与评估配置

- XGBoost：`max_depth=2, n_estimators=150, learning_rate=0.08, min_child_weight=4, subsample=0.8, colsample_bytree=0.7, reg_lambda=2, scale_pos_weight=2.0, tree_method='hist', n_jobs=1`；缺失值按训练折中位数填补；
- 评估：分层 5 折交叉验证 × 20 个随机种子（20261116–20261135），共 100 折；置换 1000 次，p=(1+#{null≥obs})/(1000+1)；
- 语义评分：DeepSeek deepseek-flash，量表 v2.0（0–10 分五档锚定，见 `docs/语义评分量表.md`），prompt v2.1（见 `docs/核验v2_prompt与聚合说明.md` 附录口径）；
- 冻结：数据文件 MD5、配置与跑批日期见 `docs/特征冻结日志.md`。

## 五、数据说明

- 样本：35 家新能源上市公司 96 个公司年度（32 个舞弊、64 个对照，按行业/年度/规模 1:2 配对）；
- 财务数据取自公开年报；历史涉财问询计数经三向交叉核查与逐函人工复核修正（38 个样本年，详见 `data/差异清单.xlsx`）；舞弊标签仅依据公开行政处罚文书；
- 许可与合规详见 `docs/数据来源与许可说明.md`；原始年报 PDF 不随仓库分发。
