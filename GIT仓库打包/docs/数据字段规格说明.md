# 数据录入规格说明（数据表_正例 / 数据表_反例 / 基准年表 配套）

> 版本 v3.1（2026-11-17）。数据拆为四张表：**《数据表_正例.csv》**（32 个舞弊年，label=1）、**《数据表_正例基准年.csv》**（7 个基数年，label=NA）、**《数据表_反例.csv》**（64 个对照年，label=0）、**《数据表_反例基准年.csv》**（35 个基数年，label=NA），另有**《数据表_全部.csv》**（138 行合并，首列「样本类型」）；各表均 **32 列**、一年一行、同构；**金额统一为元**（年报原始金额，不缩放）；行业增速并入 `industry_growth`；**表头为中英双语**（如 `rev（营业收入）`），代码端读入时自动剔除中文括号部分。**表内存年报原始科目**：销售费用与管理费用分开存（sell_exp/adm_exp），有息负债四项分开存（st_borrow/lt_borrow/bond_pay/ncl_1y），加总与指标计算全部由代码在 s2 完成——抄表只抄原样数字，不做任何手算。
> 口径唯一依据是本文件；不确定就问，不要猜。

## 一、总规则（抄表前先看）

1. **一行 = 一个公司-年度**（不是"一个样本点"）。合并键 `firm_code` + `year` 不重复。
2. **金额统一为元**（年报原始金额，不缩放），两位小数；全表金额列同单位。
3. **缺失填大写 `NA`，绝不填 0、绝不留空**。0 是"真为 0"，NA 是"没拿到"，含义不同。
4. **比率填小数**：15% 填 `0.15`。
5. **`firm_code` 6 位文本，保前导零**（如 `000040`）。Excel 里把该列设成"文本"，或全程用文本编辑器。
6. **编码 UTF-8**，数字不含千分位逗号。
7. **多填一年的规则（重要）**：每个公司从"最早一个样本年份的前一年"填起。
   - 坏公司：造假年份 + 第一个造假年份的前一年。例：青岛中程造假 2017–2022 → 填 **2016–2022 共 7 行**（2016 是"基数年"）。
   - 好公司：配对年份 + 该年份的前一年。例：某好公司配 2018 → 填 **2017–2018 共 2 行**。
   - 基数年（label 填 NA 的那行）只用来算"同比"，不参与建模。
8. **表头为中英双语**（`英文名（中文名）`）：誊抄时只看括号内中文；**请勿增删列、改名、调序**，代码端按英文名列名读取。

## 二、标识与标签（8 列）

| 列名 | 含义 | 填法 |
|---|---|---|
| firm_code | 股票代码 | 6 位文本，保前导零 |
| firm_name | 公司简称 | 如 `青岛中程` |
| year | 会计年度 | 4 位整数 |
| industry | 细分行业（新能源赛道，用于对标） | `光伏` / `风电` / `新能源车` / `锂电材料`（按"主营业务收入占比锚定法"判定，最高收入赛道为对标对象） |
| new_energy_rev_share | 新能源业务收入占比 | 新能源板块收入 ÷ 主营业务收入合计，小数（如 0.43）；从"主营业务分行业情况"逐年提取 |
| rev_reversal_amt | 分部收入冲回金额 | 当年分部收入出现**负值冲回**的金额（元），无冲回填 `0`；从"分行业"负值分部取数 |
| label | 标签 | `1`坏 / `0`好 / `NA`基数年（非样本） |
| label_source | 标签依据 | 处罚文书编号，如 `证监会处罚〔2022〕X号`；好公司与基数年填 `NA` |

## 三、财务原始科目（20 列，单位：元）

> 全部取**合并报表**原样科目，**不做任何加总**。sga（销管费用）与 debt_int（有息负债）由代码在 s2 计算：sga = sell_exp + adm_exp；debt_int = st_borrow + lt_borrow + bond_pay + ncl_1y（分项缺失按 0 计、四项全缺才 NA）。

| 列名 | 是什么 | 取数位置 |
|---|---|---|
| rev | 营业收入 | 合并利润表"营业收入" |
| cog | 营业成本 | 合并利润表"营业成本" |
| ni | 净利润 | 合并利润表"净利润"（含少数股东损益） |
| sell_exp | 销售费用 | 合并利润表"销售费用"（旧准则列"营业费用"的按当年口径） |
| adm_exp | 管理费用 | 合并利润表"管理费用"（旧准则含研发费用的按当年口径并在 note 说明） |
| ar | 应收账款 | 合并资产负债表"应收账款"**净额**（扣坏账准备后） |
| ca | 流动资产合计 | 合并资产负债表 |
| ppe | 固定资产 | 合并资产负债表"固定资产"**净额** |
| ta | 资产总计 | 合并资产负债表 |
| tl | 负债合计 | 合并资产负债表 |
| cash | 货币资金 | 合并资产负债表 |
| st_borrow | 短期借款 | 合并资产负债表 |
| lt_borrow | 长期借款 | 合并资产负债表 |
| bond_pay | 应付债券 | 合并资产负债表（无此行填 NA） |
| ncl_1y | 一年内到期的非流动负债 | 合并资产负债表 |
| oth_ar | 其他应收款 | 合并资产负债表"其他应收款"净额 |
| cip | 在建工程（可选） | 合并资产负债表；取不到填 NA |
| cfo | 经营活动现金流净额 | 合并现金流量表 |
| capex | 资本开支 | 合并现金流量表"购建固定资产、无形资产和其他长期资产支付的现金" |
| dep | 当年折旧（可选） | 现金流量表"补充资料"里"固定资产折旧"；取不到填 NA |

**抄录提示**：
- `sell_exp`/`adm_exp`、`st_borrow`/`lt_borrow`/`bond_pay`/`ncl_1y` 都是**年报原样科目**，分开抄、分开填，**不要手算相加**（加总由代码完成）；
- `ar`、`ppe`、`oth_ar` 是**净额**（扣准备后），年报资产负债表一般直接给净额，看清行名；
- `dep` 和 `cip` 最麻烦，实在取不到就整行填 NA，代码会跳过相应指标并在论文说明。

## 四、外部信号（3 列）

| 列名 | 含义 | 填法 |
|---|---|---|
| audit_opinion | 当年年报审计意见 | `0`标准无保留 / `1`带强调事项 / `2`保留 / `3`无法表示 / `4`否定 |
| inquiry_count_hist | 历史**涉财问询函计数** | 截至**预测年份 T 的 12 月 31 日**，累计该公司的**所有类型涉财问询函**（年报/半年报/季报/重组/募投/业绩预告等，不分问询函类型），涉财=+1；程序性/非涉财问询**不计入**；**关注函一律不计入**（其标题无法可靠判断涉财性，为保证口径可审计、两侧对称，整体排除）。正例与对照两侧必须用同一套判读规则（防取证不对称）。是否收到过涉财问询（原 `inquiry_finance_flag`）即 `count>0`，代码端直接由本列二值化派生，**不再单设列** |

**问询函内容判读规程（填 inquiry_count_hist 的依据，即涉财判读）**：

1. **只读问题标题，不读正文**——问询函问题均编号且有加粗标题（如"一、关于应收账款"），逐封扫标题即可，约 2 分钟/封；
2. 标题含以下任一关键词即判涉财（1）：营业收入、收入确认、应收账款、回款、货币资金、存贷、净利润、毛利率、成本、关联交易、资金占用、商誉、减值、存货、在建工程、现金流、业绩真实性；仅涉程序性事项（披露格式、换届、停复牌等）判 0；
3. **双人判读抽检（审稿意见落地）**：李政彤、董静对 10% 的问询函独立判读涉财标记，报告一致率与 Cohen's kappa；分歧条目讨论后统一标准并记录；
4. 读的同时登记《问询函核对清单.csv》（列：firm_code, 年份, 涉财, 描述, 来源），用于疑点清单证据链与数据来源核验，**明细表不进模型特征**（仅其聚合结果 inquiry_count_hist 进主表）；
5. 每家公司只查一次全部历史问询函，再对照各样本年份逐年回填计数：**只累计涉财=1 的函**，且发函年份 ≤ 预测年份 T 的才计入第 T 年（即"时间红线"= T 年 12 月 31 日）。

**行业增速已并入本表**（`industry_growth（行业增速小数）`列）：它是"某年某行业一个数"，同年同行业的所有行填**同一个值**（如 2018 年光伏全部填 0.34），由赵康佳查好后交录入组统一填入；代码端按 `year+industry` 校验全表一致性，同组出现不同值会报错打回。

## 五、数据从年报哪一章找（速查）

| 要抄的 | 年报位置 |
|---|---|
| 合并利润表 | 正文"财务报告"→ 合并利润表 |
| 合并资产负债表 | 正文"财务报告"→ 合并资产负债表 |
| 合并现金流量表 | 正文"财务报告"→ 合并现金流量表 |
| 折旧 | 合并现金流量表下方"补充资料"→ 固定资产折旧 |
| 审计意见 | 年报最前面"审计报告"第一段 |

## 六、入库质检（代码自动做，抄完自查）

1. `firm_code+year` 不重复；`firm_code` 6 位、前导零在位；
2. `industry / label / audit_opinion` 在枚举内；`inquiry_count_hist` 为非负整数；
3. 金额列是数字或 NA，无单位混入、无千分位；
4. 勾稽粗检：流动资产 ≤ 总资产、负债 ≤ 总资产；
5. 缺失率报告：`dep / cip` 整列 NA 率高时自动启用降级路径。
